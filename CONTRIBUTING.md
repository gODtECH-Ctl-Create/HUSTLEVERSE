# Contributing to HUSTLEVERSE

Thanks for helping build HUSTLEVERSE.

The project is intentionally early. Contributions should help establish a strong playable core rather than expand the scope without evidence.

## Before you code

- Read [AGENTS.md](AGENTS.md).
- Read the relevant skill in [.agents/skills/](.agents/skills/).
- Check existing issues and architecture decisions.
- Prefer a focused issue and pull request over a broad refactor.

## Good early contributions

Examples include:

- game-state primitives;
- small playable scenarios;
- deterministic simulation rules;
- NPC conversation prototypes;
- accessibility improvements;
- tests;
- documentation;
- developer tooling.

## Avoid

Do not introduce large frameworks, multiplayer infrastructure, provider-specific AI coupling, or a complete economy before the first playable loop is proven.

## Pull requests

Keep pull requests:

- focused;
- documented;
- testable;
- easy to review.

Explain the player-facing outcome and the checks you ran.

## Culture and content

Nigerian context is central to HUSTLEVERSE. Contributions should aim for recognizable, respectful situations and avoid lazy stereotypes.

## Security

Never commit secrets, API keys, private user information, or production credentials. Report security-sensitive issues privately rather than publishing exploit details in an issue.
