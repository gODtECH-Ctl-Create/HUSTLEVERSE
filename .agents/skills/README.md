# HUSTLEVERSE Skills

These are small, project-local agent skills used by the HUSTLEVERSE orchestration layer.

They are deliberately focused. The project should not accumulate a large prompt library.

## Skills

| Skill | Use for |
| --- | --- |
| [game-design](game-design/SKILL.md) | gameplay and scenario design |
| [ai-gameplay](ai-gameplay/SKILL.md) | AI, NPCs, dialogue, and model boundaries |
| [game-state](game-state/SKILL.md) | deterministic state and persistence |
| [quality](quality/SKILL.md) | tests, security, accessibility, and delivery |

Use only the skills relevant to the task.
