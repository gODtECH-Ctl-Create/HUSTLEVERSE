# Skill: Game Design

## Purpose

Design HUSTLEVERSE systems around a fun, understandable Nigerian life-simulation loop.

## Rules

- Start from the player decision and consequence.
- Prefer mechanics over cosmetic references.
- Use Nigerian context as a source of constraints, opportunities, humor, negotiation, and social systems.
- Avoid turning a culture into a collection of stereotypes.
- Keep early scenarios small enough to test.
- Define inputs, choices, outcomes, and resource changes explicitly.
- Separate flavor text from rules.

## Output

For a new mechanic, describe:

1. player goal;
2. situation;
3. available actions;
4. deterministic rules;
5. consequences;
6. what makes it replayable;
7. what is intentionally deferred.
